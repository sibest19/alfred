# transcriber

A small speech-to-text service (Python, FastAPI), published as `ghcr.io/sibest19/alfred-transcriber:<version>` (amd64). It runs [Parakeet Ultra](https://huggingface.co/moondream/parakeet-ultra) (NVIDIA Parakeet TDT 0.6B v3 post-trained by Moondream; 25 European languages, punctuation, CC BY 4.0) as ONNX through [onnx-asr](https://github.com/istupakov/onnx-asr), on an Intel GPU via ONNX Runtime's OpenVINO provider (`DEVICE=GPU`, needs `/dev/dri/renderD*` and the render group) or on the CPU (`DEVICE=CPU`). The model (`MODEL_REPO`, default `Masterx/parakeet-tdt-0.6b-ultra-onnx`, at the commit `MODEL_REVISION`, `MODEL_QUANTIZATION=fp16`) is downloaded into `/models` on first start; `/health` reports the repository and revision in use. The revision is pinned, so the model changes only with a release. Every Monday `.github/workflows/model.yml` checks the chain upstream and opens a `model-update` issue for a newer commit of the ONNX conversion, an update of Parakeet Ultra after the pinned conversion, or a new NVIDIA Parakeet model. To upgrade, change `MODEL_REVISION` (or `MODEL_REPO`) in a pull request: CI runs the transcriber smoke test on the CPU with the new model. CI has no Intel GPU, so try a clip on the GPU after deploying. GPU kernels are compiled at every start (about 30 s): OpenVINO's on-disk cache (`OPENVINO_CACHE_DIR`) is off by default, because a cached model aborted the process at its first inference on an Arc A310.

- `POST /transcribe`: audio in any format ffmpeg reads (raw body or multipart `file`) → `{"text", "duration_s", "elapsed_s"}`.
- `POST /v1/audio/transcriptions`: the OpenAI-style form of the same.
- `GET /health`: `200` once the model is loaded and warmed up.

Measured on an Intel Arc A310 (fp16): a 197 s voice note in 10 s, a 4 s one in 0.15 s; the same on a Ryzen 9 5900X CPU took 18 s and 0.25 s.
